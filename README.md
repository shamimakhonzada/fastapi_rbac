# FastAPI Feature-Based Project

Refactored application into a feature-based folder structure.

- `app/core/` for configuration, database, and shared dependencies
- `app/features/auth/` for authentication routes, services, schema, and utilities
- `app/features/users/` for user-related routes, services, schema, and repository
- `app/common/` for shared exceptions, middleware, responses, and utilities
- `app/tests/` for future test code
